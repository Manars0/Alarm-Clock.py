# Alarm Clock (Python + Tkinter)

A simple **Alarm Clock** app built using **Python's Tkinter library**.  
It lets the user set a time and plays a sound when the time is reached.

## Project Purpose
This project was created to practice working with **Tkinter for GUI design**  
and **time-based logic in Python**.
> This project demonstrates the use of basic GUI components, real-time checks, and system sound alerts in Python.
## Features
- Set a specific alarm time  
- Beep sound notification when alarm rings  
- Simple and clean GUI built with Tkinter  

## Technologies Used
- Python 3  
- Tkinter (GUI)  
- `time` module  
- `winsound` module  

## How It Works
1. The user enters the desired **alarm time** in the text box.  
2. The program continuously checks the current system time using the `time` module.  
3. When the current time matches the set alarm time:  
   - A **beep sound** is played using the `winsound` module.  
   - A **“WAKE UP”** message is displayed on the screen.  
4. The user can stop or close the app after the alert.
